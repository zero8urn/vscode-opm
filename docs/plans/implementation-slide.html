Evolution Workflow

Mapping User Intent to Data Sources

1. Discovery Lite Search & Scroll/Load More: Powered by `PackageSearchResult` stream from the NuGet API.
2. Selection Lite Clicking an item selects the existing object in `SearchState`. Instant UI update.
3. Inspection Lite Details view uses the selected `PackageSearchResult`. No second API call required.
4. Execution Lite Install/Uninstall triggers `PackageOperationCommand` using search metadata.
5. Installed View NEW A dedicated view to manage local dependencies, powered by `dotnet list package`.
